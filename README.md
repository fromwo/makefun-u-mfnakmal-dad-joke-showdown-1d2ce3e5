A tiny Node 22 program (standard library only, no dependencies, no network) that writes one original dad joke to `/output/entry.txt` for make.fun's Dad Joke Showdown. The joke is a single sentence built around a barbecue pun, with the punchline landing on the last words so it reads naturally out loud.

## Run it

```sh
node main.ts
```
